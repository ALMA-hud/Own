start - с этого места программа читается 

end - с этого места заканчивается чтение программы 

add - прибавить 

cat  - вычесть 

pad - умножить  

two - разделить

een - ровно  

oer - больше 

wee - меньше

~ - однострочные коментарий 

* * - много строчные комментарии

lap - цикл , то есть lap {} после lap число сколько раз нужно повторить код в скобках если цифры нет то код повторяется вечно в скобках код в цикле 

if и or - условие , то есть if {}or {} после if условие оно может быть абсолютно любым вот прям вообще чем угодно если оно верно то выполняется код внутри скобок if если оно не верно то выполняется код внутри скобок or и после or может быть написано дополнительное условие и верно не верно условия могут продолжать типо так if {}or {}or {}or {} и так сколько угодно вообще

ram и for - запись в ячейку ОЗУ , после слова ram пишеться адрес ячейки памяти например 0x0000 а после for что нужно записать число букву

see - чтение что записано в ячейке ОЗУ , после слова see пишется адрес ячейки памяти например 0x0000 

set - назвать запись в ячейке ОЗУ , может использоваться вместе с ram и for что бы назвать адрес ячейки название пишется после слова set позволяет легко объединять несколько ячеек памяти в одно удобное слово 

put и per - отправить данные в порт устройства , после put пишется код символа например 65 это буква-А или название ячейки памяти названая с помощью set или номер ячейки памяти к примеру 0x0000 а после per пишется адрес устройства например 0x1000-монитор 

way - принимает данные с порта устройства всегда слушая устройство без прерывания , используеться как way set после way пишиться адрес устройства например 0x1000-монитор и называеться для последующего удобного использования с помощью команды set

due - принимает данные с порта устройства с прерыванием , то есть due {} после due пишется адрес устройства например 0x1000-монитор сама команда due в отличие от way постоянно не слушает устройство если устройство ему говорит то он выполняет код внутри скобок

Команды можно писать друг на друга
